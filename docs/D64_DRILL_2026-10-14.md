# The drill of the three enabled switches on a real Docker daemon (2026-10-14)

**What this is.** `scripts/drill_reconciler_docker.py seed|play|clean`, run on the machine the development happens on, against
its own Docker daemon and its own PostgreSQL. It made the things the reconciler is meant to act on, and the things it is meant to
leave alone, and ran the **product's own command line** (`scripts/run_reconciler.py`, on a pseudo-terminal, the confirmation typed)
at fixed moments with different switches. Before each pass that was allowed to act, the same command line ran as a **dry run**
and its plan was compared, object by object, with what the drill expected at that moment; a Docker action on anything the drill did
not make, or any difference, would have stopped the drill before the real pass. (Nothing did.)

The drill refused to start with any other sandbox container on the host (there were none: the world held two old, unlabeled
containers of earlier experiments), tidied the development database's stuck test rows first (`--tidy`: 0 were found), and recorded
Docker's own event stream from the first second, so that what was killed and removed is witnessed by Docker and not by the
reconciler. The thresholds are `.env.example`'s with `RETENTION_S=180`; every run budget is 30 s.

## The seeds

| role | what it is | what must happen |
|---|---|---|
| S1 | a tool container still running past its budget + margin (no in-container deadline: the helper is the first line, this is the backstop) | killed once 30 + 60 s have passed; its corpse removed once its run has been declared unknown |
| S2 | a **real** sandbox run with its egress proxy; its control plane **killed with SIGKILL** in the middle | the proxy (no deadline of its own) removed when its bound, 30 + 60 + 915 s, passes; the tool container, which its own deadline helper stopped, once the run is declared unknown |
| S3 | an exited container, its run finished, past retention | removed |
| N1E, N1R | unlabeled containers, one exited, one running | never touched |
| N1O | only the owner label | never touched (not even seen: 5.91) |
| N1B | only the run label | never touched; reported `no_owner_label` |
| N3 | a running tool container inside a 3,000 s budget | never touched |
| N4 | an exited container inside its retention (made just before the pass that removes S3) | never touched by that pass; removed later, when its retention is over |
| N4B | the same, made just before the last pass | never touched |
| N5 | a proxy of a run still in flight, inside its bound | never touched |
| N6 | the control plane is **alive but stopped (SIGSTOP)**, and the run's deadline has just passed | not touched by the reconciler while inside the margin; then its own control plane, continued, stops and removes it |
| N2 | a container that took the name of one that was removed | never touched |
