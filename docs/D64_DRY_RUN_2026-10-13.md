**What this is.** `scripts/run_reconciler.py --mode dry-run --once`, run at **2026-10-13 02:09:55 UTC** on the machine the
development happens on, against its **own** PostgreSQL 16 database (`cyberorch`, the `reconciler_reader` role) and its **own**
Docker daemon — not against a fixture a test built. It took 3.8 s, exit 0. A dry run opens no lock, writes no audit record,
changes no row, container, network or file, and the deletion flag is off (and has no switch). The thresholds are the ones
recommended in `.env.example` (stage grace 3600 s, `B_CAP` 1800 s, retention 86400 s, network idle 3600 s, conflict window

**What "real" means here, stated plainly.** There is no production database in this container. This is the one database

`cyberorch-cred-*` / `cyberorch-tls-*` file in the temporary directory. So this run exercises the whole read path against a
database of realistic size and age (it holds the leftovers of weeks of test runs), and
it shows **no Docker or file action at all** — a host with nothing to clean. If a database with real engagements exists, the
same command with its `RECONCILER_READER_DATABASE_URL` is the run that matters, and this file is the format it would produce.

## What reading it showed

1. **The reader sees all of it.** 1,403 actions across 871 engagements through one function, no table privilege, in 3.8 s.
2. **Every action is a state change with a stated reason; nothing is a deletion.** With the flag off the Docker and file halves
   would have nothing to do here in any case.
3. **A command line that printed only what a pass carries out hid 903 of 1,403 actions.** The old output was the first 500
   results and a count; "the whole plan" was not on the screen. The command line now prints the rest and every report
   (`outcome: planned_not_carried_out_this_pass`, `{"report": …}` lines, `limited` and `held_back` in the summary). This was found by
   making this run, not by reading code.
4. **The classification flag has not been touched.** Nothing in this run depends on it, and none of it is implemented.
